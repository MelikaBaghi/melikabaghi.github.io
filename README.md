# melikabaghi.github.io

Personal academic website for Melika Baghi — Ph.D. student, H. Milton Stewart School of
Industrial & Systems Engineering, Georgia Institute of Technology.

Live at <https://melikabaghi.github.io/>.

## Structure

- `index.html` — the entire page (single file, no build step, no dependencies)
- `assets/style.css` — styles, including dark-mode and mobile layouts
- `assets/photo.jpg` — portrait shown in the sidebar
- `assets/Melika_Baghi_CV.pdf` — CV linked from the sidebar

## Editing

Edit `index.html` directly and push to `main`; GitHub Pages redeploys automatically.
Publications live in the `<ol class="pubs">` block. To add one, copy an existing `<li>`
and fill in title, authors, venue, and links.

To replace the portrait, overwrite `assets/photo.jpg` (square image, 400×400 or larger).
If the file is missing, the sidebar falls back to an "MB" monogram.
